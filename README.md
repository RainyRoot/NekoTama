# NekoTama 🐱

> Anime desktop pet for Linux Tamagotchi meets system monitor

A transparent, frameless desktop companion that lives on your screen, reacts to your system events, and keeps you company while you rice your Arch install.

**Status:** Early Development

## Features (Planned)
- Transparent, always-on-top desktop pet with sprite animations
- Tamagotchi-style stats (Hunger, Happiness, Energy, Cleanliness)
- Reacts to CPU load, RAM usage, battery, network, time of day
- Feeding system with food items spawning on desktop
- Speech bubbles (`btw I use arch`, `pacman -Syu pls`)
- XP & leveling system, skill tree, outfit evolution
- System tray integration
- Linux-first: AUR package (`yay -S nekotama`), AppImage, .deb
- Windows support

## Tech Stack
- **Electron** — transparent frameless window
- **TypeScript** — all app logic
- **PixiJS** — WebGL-accelerated sprite rendering
- **React** — settings UI
